## 🎯 Objetivo do Projeto
Desenvolver um algoritmo em formato de fluxograma utilizando a ferramenta Flowgorithm que funcione como uma calculadora contínua com menu iterativo de 11 opções.

## 🛠️ Ferramenta Utilizada
* **Flowgorithm v4.2** (Ambiente de modelagem de fluxogramas).

## 📊 Lógica de Funcionamento & Estruturas
O programa utiliza uma estrutura de repetição contínua para manter a execução ativa até que o usuário decida encerrar.
* **Estrutura de Repetição (`While`):** Mantém o menu principal rodando e atualizando o valor acumulado em tempo real.
* **Estruturas de Decisão (`If/Else` encadeados):** Direcionam a execução do programa com base na opção numérica escolhida pelo usuário.
* **Variáveis:** Controle dinâmico utilizando tipos `Real` (para números e resultados), `Integer` (para seleção de menus) e `Boolean` (para controle do fluxo de encerramento).

## 🔢 Funções Implementadas (10 Funções de Cálculo + 1 Encerramento)
1. **Adição (`+`)**
2. **Subtração (`-`)**
3. **Multiplicação (`x`)**
4. **Divisão (`/`)** *(Com validação contra divisão por zero)*
5. **Resto da Divisão (`mod`)**
6. **Potenciação (`^`)**
7. **Raiz Quadrada (`sqrt`)**
8. **Valor Absoluto (`abs`)**
9. **Arredondamento**
10. **Seno (`sin`)** *(Conversão de graus para radianos embutida)*
11. **Encerrar** *(Finaliza o loop principal e encerra o sistema)*

## 🚀 Instruções para Execução
1. Faça o download e instale o [Flowgorithm](http://flowgorithm.org).
2. Abra o software.
3. Clique em `Arquivo > Abrir` e selecione o arquivo `Calculadora.fprg` localizado nesta pasta.
4. Clique no botão **Executar** (ícone de Play verde) ou aperte `F5`.
